# zinzin66.github.io — racine du site (mémoire pour Claude)

Racine de l'adresse GitHub Pages `https://zinzin66.github.io/`. Le vrai site de
Yop2D est dans le dépôt `zinzin66/Yop2d-web` (adresse `/Yop2d-web/`) : voir son
CLAUDE.md pour l'utilisateur (non programmeur, tablette Android, français simple)
et la façon de travailler (demande de fusion vers `main`, validée par « Merge »).

Ce dépôt ne contient que ce qui doit être à la racine de l'adresse :
- `index.html` : redirection vers `/Yop2d-web/` (garde `?lang=` et l'ancre) ;
- `404.html` : page introuvable avec un lien vers le site ;
- `robots.txt` : les robots ne lisent que celui de la racine ; il donne le
  sitemap `https://zinzin66.github.io/Yop2d-web/sitemap.xml` ;
- fichiers de vérification des moteurs de recherche (Yandex Webmaster…).
  Google et Bing sont vérifiés par des fichiers dans `Yop2d-web`.
